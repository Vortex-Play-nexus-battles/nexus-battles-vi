Flujo de Trabajo del Grupo 4 (De Punta a Punta)

Cada tarjeta representa una etapa conectada mediante el token JWT y la arquitectura de microservicios de ms-identidad:

Paso 1 · Identidad

Registro de Jugador

Crea una cuenta validando formato de correo institucional, reglas de contraseña segura y unicidad de apodo en la base de datos de ms-identidad.

HU-AUT-001 Abrir Registro
Paso 2 · Autenticación

Inicio de Sesión y JWT

Verifica credenciales criptográficas, emite el Bearer JWT firmado (algoritmo HMAC-SHA256) con versión y rol, y redirige a este panel principal.

HU-AUT-004 Abrir Login
Paso 3 · Personalización

Mi Perfil y Avatares

El usuario autenticado consulta sus datos personales, redacta su biografía y selecciona su avatar de combate entre los 10 arquetipos de la galería oficial.

HU-PER-001 Ver Mi Perfil
Paso 4 · Control de Acceso

Panel de Permisos y Directiva RBAC

Muestra la matriz oficial 12×4 (48 combinaciones). La directiva reactiva has-permission oculta los módulos administrativos para el rol Jugador en tiempo real.

HU-RBAC-001 (Andrés) Inspeccionar RBAC
Paso 5 · Seguridad Perimetral

Verificación en Servidor y Fail-Closed

Demuestra cómo el SecurityInterceptor bloquea peticiones indebidas o tokens adulterados, respondiendo con código 403 RFC 7807 UTF-8 y auditoría asíncrona.

HU-RBAC-004 (Andrés) Consola Servidor
Paso 6 · Gobernanza

Gestión de Usuarios y Sanciones

Panel administrativo para buscar jugadores registrados, aplicar suspensiones temporales o baneos definitivos, y nombrar administradores.

HU-ADM-001 Gestión Admin
